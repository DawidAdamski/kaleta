# Fidelity report - 1d Dashboard, dark

Spec: [`artboards/1d.html`](../artboards/1d.html). Pictures: `.fidelity/1d/index.html` after `shoot 1d`.

`1d` is `1c` in the warm-dark token row: the same elements, the same
geometry, every colour swapped. So this report compares **colour**, and
points at [`1c.md`](1c.md) for everything that is a measurement rather than
a value - where a row there is `deviation` for a reason that has nothing to
do with the mode (the mini toggle, the search label, the group chevron, the
seed's four accounts, the icon face), it is the same here.

Read at 1360x900, drawer expanded, dark on, seeded demo ledger. Artboard
values are the inline ones in `1d.html`; app values are `getComputedStyle`
off the running page.
